# Agent Amazon — Amazon PPC Analytics

Full-stack analytics tool for Amazon sellers: upload your PPC reports and get automated analysis in under 3 minutes.

> Predecessor of [amazonanalyzer.org](https://amazonanalyzer.org) — the current production SaaS built with React + Supabase.

## Features

- Automated Amazon PPC report analysis: real TACOS & ACOS, negative keywords to block, profitable keywords to scale, campaigns to pause
- Stripe subscription payments (Pro plan)
- Supabase PostgreSQL database
- SendGrid transactional emails
- Streamlit UI, multilingual (RO/EN)
- 137+ production deployments on Railway

## Tech stack

Python · Streamlit · Supabase (PostgreSQL) · Stripe · SendGrid · Railway
